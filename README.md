# OOPJ MiniBank — Practicals 1–14

This repository contains standalone snapshots for **Part B — MiniBank** from each practical in the provided CEUE203 OOPJ practical list. `Practical01` through `Practical13` are individually runnable concept snapshots. `Practical14` is the integrated capstone with packages, persistence, validation, exceptions, repository, transactions, reporting, and a menu.

## Java version
JDK 17 or later.

## Run a snapshot (Windows CMD)
Enter a practical folder, then compile and run. Example:

```bat
cd Practical01
javac MiniBank.java
java MiniBank
```

For Practical02 through Practical13, use the same commands from that practical's folder. Practical14 has its own build commands in `Practical14/README.md`.

## Git
Generated `.class` files, `out/`, `target/`, JARs, and runtime `data/` are ignored. Commit source files and READMEs. Use tags `lab-01` through `lab-14` for the corresponding practical milestones.
