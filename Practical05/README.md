# Practical 5 — MiniBank Part B

Requirement: JDK 17 or later. This folder is a self-contained runnable snapshot for Practical 5.

## Compile and run (Windows CMD)
```bat
cd Practical05
javac MiniBank.java
java MiniBank
```

The source is kept self-contained in `MiniBank.java` to make this practical easy to compile and demonstrate. The full integrated capstone with separate packages is in `Practical14`.
